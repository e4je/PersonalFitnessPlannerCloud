# 已知限制

- 仅支持 Windows 10/11 x64；不提供 x86、ARM64、macOS 或 Linux 桌面包。
- 单文件首次运行可能因原生 SQLite 库自解压而略慢。构建后若受企业安全软件拦截，可使用 `artifacts/publish-win-x64/` 完整目录并由管理员加入可信策略；应用本身不要求提升权限。
- 离线状态不能登录、刷新角色、发布计划、分配计划或确认云端冲突；本地训练记录和 Outbox 不受影响。
- 管理身份取决于最近成功验证的后端令牌。令牌过期或无法验证时，管理写操作会被拒绝。
- 服务器优先解决已发布计划冲突；完整重新同步会保留本地草稿和训练 Outbox，但在大规模导入或切换账号前仍建议先备份。
- CSV 是扁平分析格式，不能无损还原全部快照；完整迁移请使用 JSON 导出或 SQLite 一致性备份。
- 公斤/磅显示换算存在舍入；同步和重量建议内部以公斤计算。
- Windows 与 IANA 时区规则偶有差异；跨时区旅行时请核对训练的 `local_date`。
- `Ctrl+Enter` 与 `Ctrl+S` 是全局保存组快捷键，即使焦点位于输入控件也会执行保存；其他训练快捷键会避开输入控件。
- 已发布计划不可原地修改，这是数据完整性规则而不是界面缺陷；任何修改都会创建新版本。
- 未提供自动静默更新和代码签名基础设施；企业分发时应在发布流程中添加组织证书签名与恶意软件扫描。

# 快捷键

训练执行页支持无鼠标记录。文本框、密码框或下拉框获得焦点时，`Space`、`Ctrl+Z` 等编辑按键会保留给输入控件；`Ctrl+Enter` 和 `Ctrl+S` 仍是全局保存组快捷键。

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Enter` | 保存当前组；幂等键防止连续按键重复保存 |
| `Ctrl+S` | 保存当前组（备用键位） |
| `Ctrl+Z` | 修改上一组（不会删除该组） |
| `Space` | 启动或暂停组间计时器（输入控件获得焦点时除外） |
| `Ctrl+R` | 标记休息并刷新今日建议 |
| `Ctrl+Shift+C` | 将今日训练改为有氧 |
| `Ctrl+Shift+S` | 立即同步 |
| `Ctrl+E` | 标记训练提前结束 |
| `F5` | 刷新首页建议和本地状态 |
| `Esc` | 返回首页（输入控件获得焦点时除外） |
| `F1` | 在窗口底部显示快捷键提示 |

疼痛反馈不会绑定单键，以避免误触；请在当前组明确勾选“疼痛”再保存。屏幕阅读器或输入法与快捷键冲突时，可使用页面按钮完成同一操作。

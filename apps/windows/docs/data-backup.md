# 数据备份与恢复

## 数据位置

默认目录：

```text
%LOCALAPPDATA%\PersonalFitnessPlanner\
├─ fitness.db
├─ logs\
├─ cache\
└─ backups\
```

“设置 → 数据目录”可选择其他绝对路径，中文和空格均受支持。`fitness.db` 包含训练、快照、Outbox 和同步游标；同目录的 `settings.json` 保存非敏感偏好，`auth.dat` 保存由当前 Windows 用户保护的令牌。复制 `auth.dat` 到另一台电脑或另一 Windows 用户不会自动解密。

## 创建备份

在“设置 → 备份”选择“立即备份”。应用使用 SQLite 一致性备份，而不是在数据库写入时直接复制文件。备份保存在 `backups/`，只保留最近 10 份。该备份只覆盖数据库，不含 `settings.json` 或 `auth.dat`；若要保留偏好，请在应用退出后另行备份整个数据目录。JSON 导出用于可移植数据交换，不替代完整 SQLite 备份。

## 恢复

1. 先在应用内完成同步并退出应用。
2. 复制整个当前数据目录到安全位置。
3. 在设置页选择导入 JSON，或在应用退出后按产品恢复流程选用备份数据库。
4. 重新启动，等待 migration 完成，检查计划版本、最近训练、Outbox 和同步状态。
5. 首次同步前确认 API 与登录账号正确，避免把备份导入错误账号。

不要在应用运行时替换 `fitness.db`、`-wal` 或 `-shm` 文件。不要只复制 WAL 文件。恢复较旧备份不会回退云端权威计划；下次同步仍会采用服务器计划版本。

## 导出格式

- CSV：面向表格分析，使用 UTF-8 BOM，包含日期、A/B、动作、重量、次数、容量、来源、同步状态和计划版本等字段。
- JSON：面向完整导入/归档，保留 UUID、版本、UTC 时间、`local_date`、软删除和历史快照。

导出文件可能包含健康与训练隐私，应存放在加密磁盘或受控云盘中。
